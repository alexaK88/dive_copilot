01

The problem

Underwater work is interaction-constrained.

Professional divers may need to inspect structures, record findings, follow mission tasks and communicate with surface control while their hands, vision and attention are already occupied.

Voice communication already exists in many workflows, but the information is often transient. Dive Copilot explores what happens when speech becomes a direct interface to mission state instead of something that must be reconstructed later.

01Hands occupiedInteraction must stay lightweight.
02Attention limitedThe interface cannot demand constant visual focus.
03Data must persistObservations need to become structured records.
04Intent mattersMovement, arrival, correction and messaging are different actions.

Voice as an operational interface

One sentence can change mission state.

The agent routes natural speech to explicit backend actions rather than relying on conversational memory as the source of truth.

04

Engineering

Built to test more than the happy path.

The prototype was tested around ambiguous movement, observation corrections, incomplete surface messages, repeated state queries and mission-aware terminology — the cases where a voice interface can quietly become unreliable.

PythonFastAPIJavaScriptWebSocketsREST APIsAssemblyAIPrompt EngineeringRender
FASTAPI WRITE LATENCY ~1–2 ms

Mission backend operations stayed in the low-millisecond range during testing.

SPEECH → FIRST AUDIO 2.86 → 2.55 s

Prompt simplification reduced measured first-audio latency while preserving tested tool routing.

PRIMARY BOTTLENECK IDENTIFIED Agent / tool-selection stage

Instrumentation showed that perceived latency was dominated by the voice-agent pipeline rather than backend processing.

Prototype → field system

The interaction layer is only the beginning.

The current version is a software prototype and simulation. A real deployment could connect the same interaction model to full-face-mask communications, telemetry, underwater cameras, inspection databases and surface-control infrastructure.
